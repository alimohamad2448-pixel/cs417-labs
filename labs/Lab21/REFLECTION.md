2. The benefit is that Python stays flexible and fast to write. You can add type hints for clarity without changing how the program behaves. You only pay the “type checking cost” when you choose to run mypy. The cost is that type errors can still happen at runtime if you do not check them ahead of time. Python will allow bad inputs until the code actually reaches a place where the bad type causes an error, which can allow for code experimentation and flexibility at the cost of letting less than satisfactory code pass.
